# SauceDemo Manual Testing Portfolio

A personal QA portfolio project focused on manual testing of the
SauceDemo e-commerce demo application.

This project is being developed to demonstrate test planning,
test case design, test execution and defect reporting.

## Application Under Test

SauceDemo: https://www.saucedemo.com/

## Planned Testing Scope

- Login and validation messages
- Product listing and sorting
- Adding and removing products from the basket
- Checkout form validation
- Completing an order
- Logout

## Project Documents

| Folder | Purpose |

## Project Status

In progress. Existing documents are being reviewed and expanded.
Test results will be recorded after execution, with evidence for
any defects found.
